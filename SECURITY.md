# Security policy

Do not open a public issue containing credentials, private context, signing keys, capsules, or database contents.

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/amiencoy/parabiont-protocol/security/advisories/new). Include a minimal synthetic reproducer and affected version. Revoke any exposed bond or key locally; a report cannot provide remote forgetting for context already delivered to a model.

This project is an experimental reference implementation. Its supported boundary is the loopback-only profile documented in the README; remote deployment is not supported.
